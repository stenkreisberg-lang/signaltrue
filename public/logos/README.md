# Customer logos

Drop a company's official logo here (SVG preferred, single colour) and
reference it from `src/components/CustomerBand.tsx`:

```ts
{ name: 'Cleveron', logo: '/logos/cleveron.svg' }
```

It renders in place of the typographic wordmark, grayscale at the same
height as every other mark.

Keep written permission on record before publishing a logo. Cleveron and
Tehnopol both require approval for non-editorial use:

- https://cleveron.com/press/press-materials/
- https://www.tehnopol.ee/en/about/logo-and-style-guide/
