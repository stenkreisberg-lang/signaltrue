Do not request employee data or real risk-assessment documents. Use the fictional situation below. Record anonymous session IDs; keep identities, recordings and attributable quotations in an authorised private location, not this public repository.

## Five-minute moderator script

Opening: “We are checking the page, not your expertise. Please say what you think it means. I will not explain it until the end.”

1. Show the introduction briefly, then hide it. Ask: “What would you expect this page to help you do?” Record the answer before prompting.
2. Show it again. Ask: “What would you expect to receive? What would you need to provide? Would you need an account or email address?”
3. Fictional task: “A team has reduced recurring meetings, but nobody has agreed what evidence would show that the change helped. Where would you start on this page?” Ask the participant to point, not complete a production assessment.
4. Show the first question and its response options. Ask: “What situation are these options asking about? Could you choose an option for the fictional example? What is missing or unclear?” Do not coach an answer or force a choice when the scenario lacks facts.
5. Show the illustrative result. Ask: “What does this result establish? What does it leave unanswered? What would you do next?”
6. End with: “What, if anything, would stop you using this?” Do not ask whether the page is good, impressive or worth buying.

## Predeclared decision rules

If two independent intended users misunderstand the same purpose, prerequisite or result limitation, prepare one bounded copy/structure correction at that point and retest it. Treat this as directional qualitative evidence, not a statistical threshold.

If people understand the page but say the situation is irrelevant, record audience/problem fit separately; do not assume a prettier CTA will fix it. If a control is unclear only in the static capture, validate in an isolated interactive session before changing navigation.

If comprehension is sound, keep the copy and continue investigating eligible traffic and real event receipt. Never relabel missing GA4 events as confirmed abandonment.

After any approved revision, measure first-answer started and completed events with matching page/session cohorts; report-save success, qualified employer enquiry, pilot discussion and customers remain separate stages. Initial research success is a specific observed obstruction or a clear decision to leave the page alone. It is not conversion uplift.
